# filing-to-factor gap

This project studies whether as-filed fundamentals and filing-complexity frictions predict the cross-section of U.S. equity returns after filings become public.

The public documentation emphasizes reproducibility, data timing, visual diagnostics, and model/backtest tables. Proprietary WRDS extracts are not redistributed.

The final private run covers 247,806 filing observations and 7,057 linked CRSP firms through 2026 YTD. Public artifacts report aggregate results only, including model scorecards, FF alpha, event-study tables, robustness slices, and publication-ready figures.
